## Descripción 

<p>
  Con la intención de contribuir al cuidado del medio ambiente mediante la disminución de generación de desperdicios, se realizó este sitio web
  para facilitar el intercambio de productos entre usuarios.
</p>
<p>
  Es decir, se busca lograr que los productos no perecederos tengan una segunda vida y se logre así atrasar el tiempo en el que estos llegan al basurero,
  de esta forma se impacta tanto directa como indirectamente en la generación de basura que termina contaminando las calles, rios, mares, etc.
</p>

## Funcionalidades

<p>
  Algunas de las funciones que el sitio web permite a los usuarios son:</p>


  - Registrarse con su correo electrónico 
  - Iniciár sesión
  - Navegar a través del sitio para ver los articulos publicados
  - Subir su propio articulo(Nombre, imagen del objeto y ubicación)
  - Comentar en publicaciones de productos de su interés
  - Ver detalles de su pérfil (articulos publicados, nombre de usuario, etc.)


## Tecnologías utilizadas

<p>
  Este es un proyecto simple pero funcional, se optó por usar <em>HTML y CSS</em> para el Front-end.
  Para el Back-end se utilizó <em>Python</em>, especificamente <i>Django</i>, ya que se consideró una opción factible para el tamaño del proyecto.
  De igual forma se utilizó <i>Bootsrap</i> para ciertos detalles de la interfaz.
</p>
